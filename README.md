# Expense Tracker Dashboard

A simple expense tracking application built with Python and Streamlit. It helps users record expenses, monitor monthly spending, and compare expenses against a budget.

## Features

- Add expenses with a name, category, amount, and date.
- Set a monthly budget.
- Filter expenses by month.
- View monthly spending totals.
- Visualize spending by category.
- Delete recorded expenses.
- Download expense records as JSON.

## Technologies Used

- Python
- Streamlit
- JSON

## Run Locally

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required package:

   `pip install -r requirements.txt`

5. Run the application:

   `streamlit run expense_dashboard.py`

## Project Purpose

This project was built to practise Python programming, file handling, data management, and interactive dashboard development.

## Note

This is a learning project. The deployed demo is not intended for storing private or sensitive financial information.
